# 怎么拿到邮箱的授权码

OfferCrew 要连上你自己的邮箱，才能读到招聘方的回复、替你发出你批准过的信。连邮箱不用你的登录密码，用的是一串**授权码**：在邮箱网站上自己生成，粘贴进 OfferCrew。

现在能连的邮箱：QQ 邮箱、网易邮箱（163、126、yeah.net）、iCloud 邮箱、Gmail（个人账号）、Yahoo 邮箱。

## 先说清楚几个词

- **授权码**：邮箱专门给「别的邮件软件」用的一串密码，和你登录网页用的密码不是一个。各家叫法不同：QQ 和网易叫「授权码」，iCloud 叫「App 专用密码」，Gmail 叫「应用专用密码」，Yahoo 叫「应用密码」。它只能用来收发信，不能拿来登录邮箱网站、改密码。不想用了，在邮箱网站上把它删掉，它立刻失效，你的登录密码不受影响。
- **IMAP / SMTP**：邮件软件收信、发信用的两种通用方式。IMAP 管收信（OfferCrew 只读你的收件箱），SMTP 管发信。QQ 和网易要先在设置里把它们打开，iCloud、Gmail、Yahoo 一直开着。

## 粘贴到 OfferCrew

1. 在新手引导的「邮箱」一步，或者「设置 → 账号与连接 → 邮箱」里，确认邮箱地址。OfferCrew 会按地址认出是哪家的邮箱，告诉你要哪一种码。
2. 照下面对应的那一节拿到授权码，粘贴进来。中间带空格也没关系，粘贴时会去掉。
3. 点「测试」。OfferCrew 会用这个码登录一次，读出你收件箱里最新一封信的标题给你看，再试一下发信服务器能不能登录（不会发信）。看到标题，就说明连通了。
4. 点「保存」。

<a id="qq"></a>

## QQ 邮箱

1. **登录网页版**：打开 [mail.qq.com](https://mail.qq.com)，登录你的 QQ 邮箱。
2. **打开设置**：点「设置」，进「账号」这一页（新版网页叫「账号与安全」）。
3. **开启服务**：往下找到「POP3/IMAP/SMTP/Exchange/CardDAV 服务」，把「IMAP/SMTP 服务」打开。
4. **验证并生成授权码**：按页面提示，用绑定的手机发一条短信验证。验证完，页面上会显示一串 16 位的授权码。
5. **复制**：把这串授权码复制下来，粘贴到 OfferCrew。以后要再连，可以在同一个地方点「生成授权码」再生成一个。

foxmail.com 的邮箱也是 QQ 邮箱，步骤一样。

<a id="163"></a>

## 网易邮箱（163、126、yeah.net）

1. **登录网页版**：打开 [mail.163.com](https://mail.163.com)（126 邮箱是 [mail.126.com](https://mail.126.com)），登录。
2. **打开设置**：点页面顶部的「设置」，选「POP3/SMTP/IMAP」。
3. **开启服务**：把「IMAP/SMTP 服务」打开。按提示用绑定的手机扫码或发短信验证。
4. **拿到授权码**：验证完会弹出一串授权码（以后也可以点「新增授权密码」再要一个）。**它只显示这一次**，马上复制下来。
5. **粘贴到 OfferCrew**。

网易要求邮件软件登录时报上自己的名字，否则会拒绝读信（提示「Unsafe Login」）。OfferCrew 会自动报，你不用做什么。

<a id="icloud"></a>

## iCloud 邮箱

iCloud 的这串码叫「App 专用密码」。要先给 Apple 账户打开**双重认证**（大多数账户已经默认打开了）。

1. **登录**：打开 [account.apple.com](https://account.apple.com)，用你的 Apple 账户登录。
2. **找到 App 专用密码**：进「登录与安全性」，点「App 专用密码」。
3. **生成**：点「生成 App 专用密码」（或者「+」），名字填 `OfferCrew`，方便以后认出来。按提示再输一次 Apple 账户密码。
4. **复制**：把显示出来的那串密码（形如 `abcd-efgh-ijkl-mnop`）复制下来，粘贴到 OfferCrew。连字符要保留。

me.com、mac.com 的邮箱也是 iCloud 邮箱。用 iCloud+ 自定义域名收信的，登录名要填你的 iCloud 邮箱地址（@icloud.com 那个），授权码照样是 App 专用密码。

<a id="gmail"></a>

## Gmail（个人账号）

Gmail 的这串码叫「应用专用密码」。要先给 Google 账号打开**两步验证**。

1. **打开两步验证**：登录 [myaccount.google.com](https://myaccount.google.com)，在「安全性」里打开「两步验证」。已经开了就跳过这一步。
2. **打开应用专用密码页**：打开 [myaccount.google.com/apppasswords](https://myaccount.google.com/apppasswords)。
3. **创建**：应用名称填 `OfferCrew`，点「创建」。
4. **复制**：把显示出来的 16 位密码复制下来，粘贴到 OfferCrew。它只显示这一次。

要注意：

- **在中国大陆连 Gmail 要代理。** 代理软件（ClashX 这类）打开「设置为系统代理」，OfferCrew 连 Gmail 时就会走它；在终端里运行的 OfferCrew 也认环境变量 `HTTPS_PROXY`、`ALL_PROXY`（比如 `socks5://127.0.0.1:7890`）。测试时如果显示「连不上」或「超时」，多半是代理没开，不是授权码的问题。
- **学校、公司的 Google 邮箱用不了应用专用密码**，见下面「学校和公司的邮箱」。

<a id="yahoo"></a>

## Yahoo 邮箱

1. **登录**：打开 [login.yahoo.com](https://login.yahoo.com)，登录后点右上角的名字，进「账户信息」。
2. **找到应用密码**：进「账户安全」这一页，找到「生成应用密码」（有的页面叫「管理应用密码」）。
3. **生成**：应用名称填 `OfferCrew`，点「生成密码」。
4. **复制**：把显示出来的密码复制下来，粘贴到 OfferCrew。

yahoo.co.uk、ymail.com 这些地区和别名的 Yahoo 邮箱，步骤一样。Yahoo! JAPAN（yahoo.co.jp）是另一家公司，现在连不上。

## 学校和公司的邮箱

学校、公司的邮箱（Microsoft 365、学校的 Google 邮箱、腾讯企业邮、网易企业邮这类）现在连不上：它们要学校或公司的管理员批准，或者要 Google、微软审核。

先在学校、公司邮箱的设置里，把邮件**自动转发**到你的个人邮箱（QQ、163、iCloud、Gmail、Yahoo 都行），再让 OfferCrew 连那个个人邮箱。有的学校不允许自动转发，那就在投递时直接留个人邮箱。

Outlook、Hotmail 的个人邮箱要用微软账号登录，排在后面一版。

## 要注意的

- **授权码相当于密码。**它只存在你这台电脑上（数据目录的 `private/mail/`，不进 Git），用钥匙串里的一把密钥加密，不写进日志，也不发给任何服务器。不要发给别人，也不要截图发到群里。
- **改了邮箱密码，授权码会失效。**QQ、网易、Google、Apple 都是这样。OfferCrew 发现连不上时会提示你重新填一个。
- **OfferCrew 只读收件箱里的新信。**不删信、不移信，也不会把信标成已读。第一次连上时从当时最新的一封往后读，以前的信不读。发信只发你批准的那一版。
- **只看和求职有关的信。**对得上你投过的岗位的，或者看着是招聘方、招聘系统发来的，才会记下来；银行、购物、私人的信不记，也不交给模型。
- **判断一封信是哪一类，要用你选的模型。**交给模型的只有发件人、标题和对方新写的那段（引用的旧信去掉）。用 OfferCrew 补给时，这些内容会经过 OfferCrew 的中转再交给模型服务商；中转只记用了多少点，不保存内容。
- **什么时候收信**：09:00–21:00 之间，工作台开着（Mac App 开着就算）时，有新信就读；命令行安装另外每小时查一次。晚上到的信，第二天早上接着读。
- **不用了**：在 OfferCrew 里断开，本机保存的授权码就删了；再到邮箱网站上把这个授权码删掉，它就彻底失效。

## 已知局限

- **钥匙串里的那把密钥，本机别的程序也读得到。**它是用 macOS 自带的 `security` 命令存的，这样存的条目，这台电脑上别的程序也能用同一个命令读出来。Mac 版下一个版本会换成只有 OfferCrew 自己能读的存法。
- **代理只认两种来源**：macOS 的系统代理（HTTP、HTTPS、SOCKS，只用来连 Gmail），和终端里的环境变量。自动代理配置（PAC）不认；App 里手动填代理，后面一版再做。
