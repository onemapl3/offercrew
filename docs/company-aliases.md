# 公司别名

公司字段统一去掉名称末尾的“集团”或“ Group”，以及公司网站写法的 `.com`、`.cn`、`.net`、`.org`。`示例商贸（EXCO，海外总部）` 会识别括号中的英文公司名；城市、远程等地点说明不作为别名。

无法从名称本身证明的跨语言或简称关系，放在你自己的数据目录 `config/company-aliases.json`。文件是一组组名称，每组第一项是希望显示的公司名，例如：

```json
[
  ["示例商贸", "EXCO", "Example.com", "Example Group"]
]
```

别名表供线索入库、旧字段修复、重复线索识别、公司资料查询和发现排除规则共用。修改配置会刷新名称匹配和排除缓存，下一次线索写回使用新的显示名。原始字段和投递历史仍保留。

没有别名表时只做通用规范化，不猜中文名和英文名的关系。文件仅存本机，已被 Git 忽略；公司的真实名称和投递记录不要放进代码、测试或公开模板。配置不存在时使用空表，格式错误会明确报出，不悄悄丢掉别名。
