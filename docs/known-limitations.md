## 专用 Chrome（docs/chrome-host.md）

- Mac 上专用 Chrome 和你平时的 Chrome 是同一个程序：平时的 Chrome 没开、只开着专用 Chrome 时，点程序坞里的 Chrome 图标打开的是专用 Chrome；两个都开着时，程序坞里有两个 Chrome 图标。闲着 10 分钟、没有给你看的标签页就自动关掉，退出 OfferCrew 时也一起关掉，可以减少这种情况，但避不开（不另外下载一个浏览器就没有办法）。
- 专用 Chrome 关掉再开，只在会话期间有效的登录会丢，要再登一次。
- 招聘官网的登录检查，「已登录」的证据还没在真的登录状态下核对过（config/accounts.json 里 confirmed:false），这些网站登好后系统不一定能自己发现，要回来点「我登好了」。Workday、飞书招聘、Moka 还没有登录检查。
- 有界面的行为（后台开窗口不抢焦点、把窗口拉到最前面）还没在有界面的 Chrome 上实测过，只在无头浏览器上测过。
