# 预设：选了「我是谁、想做什么」之后，一键带上的一整套

新用户打开「开始使用」，第一步回答两件事：

- **你现在的身份**：在校生、应届生，还是职场人；
- **你想做哪个方向**：工程师，或者产品经理、数据分析、UI/UX 设计、运营这几个入门方向。

选完以后，系统按这个方向带上一套默认值，这套默认值就叫**预设**。里面的每一项都可以改，也可以整个去掉。

一套预设包含下面几样东西：

1. **判断口径**：哪些岗位算你的方向；标题里哪些词说明级别偏高；实习怎么折算成年限；常见证书有哪些。工程师多一张大厂职级对标表，比如 P7、2-2、T3 大概要几年经验，仅供参考，见 `lib/directions.mjs` 的 LEVELS。
2. **公司包**：`config/company-packs/tech.example.yaml`。这 34 家公司，每一家都在 2026-09-29 用我们自己的适配器实际读到过岗位，才放进包里。还读不到的公司（需要新适配器，或者接口读不出来）列在文件末尾，写了原因。
3. **真人渠道包**：`config/channel-packs/<预设>.example.json`。它写明四件事：
   - 从哪里读真人发的招聘帖；
   - 每个来源默认开还是关；
   - 按这个方向用什么搜索词；
   - 每项为什么这样设。

   其中，要登录的来源默认关着。BOSS 直聘的条款禁止自动化，所以这里只给你一个搜好的入口，由你自己打开看，不做批量打招呼。
4. **简历提示**：写简历时要注意的几条，按子方向补充。
5. **默认预算档**：省钱、标准、高级。具体执行由用量那边的成员 Ledger 负责，这里只写档位的名字。
6. **面试准备要点**：按子方向列出要准备哪几块。面经默认去牛客、力扣讨论区、脉脉找。

工程师没选子方向时，一切照旧（作者本人就是这样）。选了子方向以后，筛选、排序、搜索词、判断时问模型的问题，都按你选的子方向来。

说明：

- 表里「简历提示」「面试准备」列的是整个方向通用的条目。选了子方向会再补几条，比如后端会补「写并发量、延迟、可用性和数据量级」，面试准备会补「系统设计、数据库与索引、并发与分布式」。
- 入门预设和工程师用的是同一批科技公司，国内门户的搜索词会按方向自动换，所以公司包是同一份，按 `presets` 标记分给各个方向。
- 金融、咨询等方向在第三阶段加，见 `design/non-tech/RESUME.md`（仓库外）和 `docs/channels.md` 第九节。
