# 材料：简历、求职信、自我介绍

工作台左栏的「材料」页（`#materials`，旧地址 `#resume` 会自动跳过来）。这里放你投递时要用的东西：简历的各个版本、求职信、自我介绍。团队里管这些的是 Writer。不投递，光改简历也能用。

做法和「文件 + 对话」的工具一样：每一份都能打开、直接改、自动保存；也可以在右边的对话里叫 Writer 改，改出来的是新的一版，原来那版不动。

## 材料首页

- 三个标签：简历、求职信、自我介绍。右上角是「中文 / English」（有两份简历时切换）和「上传简历」。
- 上面一张卡是默认投递的那一版：缩略图、名字、谁改的、用在几个岗位，按钮是修改、预览、导出 PDF。
- 下面是「全部版本」，从新到旧。每一行写着版本名、谁改的（你、Writer、上传）、基于哪一版、日期、用在几个岗位。
  - 按岗位定制的版本缩进挂在它出发的那一版下面；还没点「用这版」的，行上标「等你确认」。它也是一版，算在件数里。
  - 「⋯」里有设为默认投递、另存为新版本、改名。
- 求职信、自我介绍两个标签：每一封一行（给哪个岗位、谁写的、在用 / 等你确认 / 核对没过），Writer 改出来的几版缩进挂在第一版下面。点一行打开那一封。

## 一份简历的页面

- 正文就是一张纸，排版和导出的 PDF 用同一套样式。点哪里改哪里：回车起新的一行，空行上按退格删掉这一行，Alt+↑ / ↓ 挪动，⌘B 加粗，行尾的「+」加一段经历或一节。
- 自动保存。⌘Z 撤销、⇧⌘Z 重做；「历史」里能回到任意一步，或者另存为新版本。
- **每一版都能改，原简历（v1）也能。** 你上传的原件在后台另存一份，它只有两个用处：
  - 出处核对的依据永远是这份原件，而不是 v1 现在的内容；
  - 某一版和原件一字没改时，投递直接上传你的原件；改过就导出这一版自己的 PDF，原件不会被覆盖。
- 顶栏右边是 Writer 的两个按钮「体检」「改一版」，然后是撤销、历史、导出 PDF。
- 还没点「用这版」的定制版，顶栏有「用这版投 #N」；点了以后写「#N 投递在用」。

## Writer 能做的四件事

都在右边的对话里（⌘K 打开）。材料页开着某一版时，对话输入框上面写着「正在看 简历 v4 · 通用版」，在纸上选中几行还会加上「· 选中 N 行」；这时说「这几行……」，Writer 就知道指的是哪几行。材料页上 Writer 是预先选好的。

1. **体检**：只看不改，列出几处可以改的地方；点一条，纸上那几行闪一下。末尾有「按这几条改一版」。
2. **改一句**：选中几行再说，或者在对话里点名哪一段。直接改上去，改过的行标黄，对话里带「撤销」。
3. **改一版：先问，再改。**
   - Writer 先在对话里问 2–4 个问题，每个问题有可以点的选项，也能自己补一句；找不到出处的事实也在这一步先问。
   - 你点「开始改」它才动手；没答的题算跳过。
   - 改完直接存成新的一版，原来那版不动。对话里给一张版本卡片：「打开」进那一版，「和上一版对比」是一个小入口，可以不点。
   - 你回答的事实会记下来，成为那一段经历的出处。
4. **按岗位定制**：在岗位页「材料」标签的「换一份 ▾」里点「按岗位定制」，对话面板打开，Writer 照「先问后改」去做。
   - 做完以后收件箱来一封信：「<公司 · 岗位> 的定制版好了」，有「打开看看」「用这版」两个按钮。手机推送照收件箱的规矩走。
   - 你点了「用这版」（在信上、那一版的页面上、或岗位页上都行），这个岗位投递时才用定制版。没点，就照旧用默认投递那一版。
   - 终审信照样写明这次实际上传的是哪一份。

你自己写的字找不到出处时，Writer 停手几秒后在对话里提醒一句（同样的字只说一次）；正文上不挂任何东西，也不拦你。

## 只改写，不编造

只在提示词里写「不要编造」是不够的，这里由代码按行核对。Writer 写出来的每一行都要拆开核对，不只看数字和名词，也看担当（「参与」不能变「主导」）和用词。核对不过的行退回原文，新加的、找不到出处的行丢掉。

「出处」只认三样东西：

- 你上传的原件；
- 个人资料 `candidate/facts.yaml`；
- 你回答 Writer 的问题时亲口说的话。

具体查这几类：

| 查什么 | 举例：会被拦下的改写 |
|---|---|
| **数字**：每个数字都要在这段经历的原文或资料里出现过，数值一致；原句里的数字不能删 | 原文没有数字，改后写成「提升 40%」 |
| **技能和名字**：改后出现的工具、技术、公司名，这段经历里要有 | 原文只写了 Python，改后多出 Kubernetes |
| **担当**：不能把角色说大 | 原文写「参与开发」，改成「主导开发」 |
| **谦辞**：原句里的「参与、协助、helped」，改后要保留 | 「协助市场部复盘」改成「完成市场部复盘」 |
| **成果**：转化率、营收、延迟、用户数这类成果，原文要提过 | 原文没提延迟，改后写「降低了延迟」 |
| **其余的话**：要么是原话，要么是意思相同的普通说法，要么是连接词 | 改后冒出「高并发、千万级」这种原文没有的说法 |

核对宁可错拦，也不放过。你自己写的字算你的话：找不到出处只提醒，不拦。

## 某个岗位投递时用哪一份

岗位页的「材料」标签只有一句话说这件事：「投递会用《英文 · v3 · 通用版》」，后面写「Reacher 选的」或「你选的」，旁边是「预览」和「换一份 ▾」。下面列出这个岗位的定制版，标「等你确认」（带「用这版」）或「在用」。已经投出去的，写当时上传的那一份。

规矩（`lib/resume-choice.mjs` 的 `pickResume`）：

1. 你在「换一份」里选过的，优先；
2. 其次是为这个岗位做的、你点过「用这版」的定制版（有几份取最新的）；
3. 最后是默认投递里和 JD 同语言的那一版（缺这种语言就用另一种；设置里配了这种语言的投递文件时，传的就是那个文件）。

「换一份 ▾」里有：这个岗位的定制版、其他各个版本、「让 Reacher 选」（清掉你的选择）、「按岗位定制」。选了别的那一版，那封「定制版好了」的信就收起。

投递时把那一版导出的 PDF 上传，文件名照旧好认（例如 `Alex-Example-Resume.pdf`）。填表时把当时的 PDF 和纯文字一起留底在这条投递的记录里，之后再改那一版，留底不变。

## 求职信和自我介绍

- 打开以后和简历是同一种页面：一张纸，点进去就改，自动保存，⌘Z 撤销；顶栏有 Writer 的「改一版」和「用这封」。
- 「改一版」也是先在对话里问几句（语气、篇幅、想多说哪段经历，都带选项，也能自己补一句），答完写成这封信的新一版（第 2 版、第 3 版……），原来那封不动；对话里一张版本卡片，「打开」进新的那一版。几版之间在顶栏切换，你点「用这封」的那一版才算数。
- 写之前先读这家公司的调研和岗位描述。没有调研就写明「没调研，按通用版写」，信里也不许出现关于这家公司的具体事实。
- 逐句核对出处：说「我」的句子，数字、名字、技能只能来自你的材料（句子点名了哪段经历，就只认那一段）；说公司的句子，只能来自调研和岗位描述。核对没过的那封不给直接用，你自己改过以后就能用。
- 一封信可以给几个岗位用：在岗位页「材料」标签求职信那一行的「换一份 ▾」里选。
- 自动投递填表时，求职信那一栏用这个岗位选定的那封；申请表要求必填求职信而你还没选，投递停下来等你，你点了「用这封」后自动接着填表。内推请求优先用你选定的自我介绍。

## 模型和隐私

- 所有模型调用都走设置里配的文字模型，调用时没有工具、不能读文件。简历正文、岗位描述、公司调研都当作不可信的材料处理。
- 在演示 / 沙盒模式下不调用模型，Writer 照实说「模型用不了」（一段对话里只说一次），下面这些照常能用：
  - 自己改简历和信、版本、撤销、导出；
  - 体检里由代码查得出的几条（错别字、缺数字之类）；
  - 改一封信之前的那几个问题（不跑模型）。
- 所有数据都在 `candidate/resume/` 里，这个目录不进仓库：
  - `workspace.json`：有哪几份简历；
  - `<编号>.json`：每一份简历的全部状态（版本、历史、你的回答）；
  - `<编号>/original/`：上传的原件；`<编号>/<版本>/`：导出的文件；
  - `choices/`：每个岗位你选的简历和求职信；
  - `letters/`：求职信和自我介绍（几版各一份）。

## 代码在哪

| 文件 | 做什么 |
|---|---|
| `lib/resume-store.mjs`、`lib/resume-versions.mjs` | 存取、版本、编辑、撤销、导出、默认投递 |
| `lib/resume-doc.mjs`、`lib/resume-provenance.mjs` | 切分、证据、出处核对 |
| `lib/resume-check.mjs` | 体检 |
| `lib/resume-writer.mjs` | Writer：体检、改一句、先问、改一版、定制 |
| `lib/resume-talk.mjs` | 对话里的 Writer：分类、问题卡、版本卡片、提醒 |
| `lib/resume-choice.mjs` | 某个岗位用哪一份（`pickResume`、`leadMaterials`、`chooseLetter`） |
| `lib/resume-tailor.mjs` | 按岗位定制、「定制版好了」的信、`tailor_accept` |
| `lib/resume-letters.mjs` | 求职信、自我介绍：写、改、几版、核对 |
| `lib/resume-export.mjs` | 导出 PDF 和 Word |
| `web/resume.js`、`resume-editor.js`、`resume-letter.js`、`resume-compare.js` | 材料首页、简历页、信的页面、两版对比 |
| `web/hq.js`（`matHtml`） | 岗位页的「材料」标签 |
